# LeadPulse AI

LeadPulse AI is a dashboard frontend for a predictive lead generation and intent scoring system for finance and real estate.

## Features

- Lead management dashboard
- Lead intent scoring interface
- Sample lead data for demonstration
- Dashboard interface built with Vite and JavaScript frontend tools

## Run Locally

### Prerequisites
- Node.js and npm

### Installation

```bash
npm install
npm run dev
```

Open the local URL displayed in your terminal, usually `http://localhost:5173/`.

## Demo Data

Sample data is stored in `src/data/demo.js`. The dashboard currently uses this data for demonstration.

## Backend Status

The Flask API integration is not included in this frontend folder. Backend functionality requires a separately configured API service.

## Note

The localhost URL is for local development only. A public URL requires deployment to a hosting service.
